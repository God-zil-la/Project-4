🤖 Connect {{ bot.name }} to Discord

  1. Create a Discord bot token
    (Go to the Discord Developer Portal → Bot → “Copy token”)
  2. Invite Your Discord Bot to Your Server
    To connect your own Discord bot with our AI Assistant platform, you will need to authorize it in your server.
    • Log in to the Discord Developer Portal and locate your bot.
    • Copy your bot’s Client ID (also called Application ID).
    • Paste your Client ID in the field below.
    • Click Generate Invite Link to create a personalized authorization link.
    • Click the generated link to invite your bot to your Discord server.

    Once authorized, your bot will be ready to communicate securely with our platform.


  3. Download the bridge bundle
    bridge.py env.example requirements.txt
  4. Edit .env — paste your secrets: 
    {{ example_env }}
  5. Run locally
    (copy & paste the right version for your system) This sets up your Python environment so the bridge can run on your computer.

    💻 For macOS / Linux: 
    python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bridge.py
    💻 For Windows (PowerShell or CMD): 
    python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bridge.py
  6. Leave that terminal open — your bot is live 🎉
