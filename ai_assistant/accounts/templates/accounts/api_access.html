Send a message

POST JSON to /accounts/api/public-chat/ over HTTPS. Set X-API-KEY to your secret and Content-Type to application/json.

{"bot_id": 123, "message": "Hello"}

Use an assistant ID from My AI Assistants. A successful response includes response and conversation_id. To continue, send that ID as conversation_id. Omitting it starts a new conversation.

Errors: 400 invalid request, 401 invalid key, 403 Pro or usage restriction, 404 assistant unavailable, 429 request limit, 500 processing failure. For 429, wait the returned retry_after_seconds. Do not automatically retry uncertain or timed-out chat requests.
