02 / Quick start

Send your first message

1. Choose an assistant

Find its ID in My AI Assistants.

2. Send a request

POST JSON over HTTPS with your server-side API key.

3. Continue chatting

Reuse the returned conversation_id to keep the conversation going.

Endpoint

POST /accounts/api/public-chat/
X-API-KEY: YOUR_SECRET_API_KEY
Content-Type: application/json

JSON request body

{"bot_id": 123, "message": "Hello"}

Replace 123 with your assistant ID. A successful response includes response and conversation_id. To continue, send that ID as conversation_id. Omitting it starts a new conversation.

Response and error handling

400 invalid request · 401 invalid key · 403 Pro or usage restriction · 404 assistant unavailable · 429 request limit · 500 processing failure.

For 429, wait the returned retry_after_seconds. Do not automatically retry uncertain or timed-out chat requests.
